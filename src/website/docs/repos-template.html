SDK

{{GH}}

bitcoin-arena/arena-sdk

What an app imports from Bitcoin Arena: manifests and their signing, hashing, donations, series, the order book, contracts and the host. An app names it in its package.json as github:bitcoin-arena/arena-sdk#<tag>. It is packed from packages/arena-sdk in bitcoin-arena; changes go there.
