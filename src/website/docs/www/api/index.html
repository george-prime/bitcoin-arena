Node API reference

Every request a Bitcoin Arena node answers, 272 in all, as an OpenAPI 3 document generated from the node's source (packages/arena-node/src/server.js). Open a request, press Try it out and Execute to ask a live testnet4 node. The prose, the concepts and how to build a game are in the docs.

Live serversThe 14 public testnet4 seats, from https://tn4.bitcoin-arena.io/guardian-1. Pick another in the Servers box; every seat answers for itself.
Read-only hereOnly GET requests can be run from this page. Requests that change something are documented, and marked when they need a signature or an operator token.
Live examplesThe round id in the examples is read from the first server's /rounds when this page opens, so ?round= requests answer 200.
